# puzzleGames
# Game with Browser Interface

## 📌 Project Overview

This project focuses on building a small, interactive puzzle system by integrating **Java backend logic** with a **lightweight browser-based interface**.

We begin by developing the core game engine in Java, where puzzle data is loaded from text files and processed using simple algorithms. These algorithms generate different types of puzzles using randomness and pattern-based logic.

To make the system interactive, the backend logic is connected to a minimal frontend through an embedded Java web server. The server exposes puzzle data over HTTP and renders it in a clean, browser-accessible interface.

By the end of the project, the application runs backend logic, serves puzzle content via a local server, and displays results in a web browser.

---

## 🎯 Project Objectives

- Build a puzzle game engine using Java  
- Read and process data from text files  
- Apply basic algorithms for puzzle generation  
- Use randomness and pattern generation techniques  
- Implement a lightweight embedded HTTP server  
- Display puzzle output in a browser-based interface  

---

## 🛠️ Concepts Covered

- Java classes and object-oriented programming  
- File I/O operations  
- Random number generation  
- Pattern and puzzle logic  
- Basic HTTP request handling  
- Backend-to-frontend data flow  

---

## 🔄 Application Workflow

1. Java backend loads puzzle data from text files  
2. Puzzle logic generates game output using algorithms  
3. Embedded web server exposes puzzle data  
4. Browser requests puzzle via HTTP  
5. Puzzle is displayed in a clean UI  

---

## 🧑‍💻 Technologies Used

- Java (JDK 8 or above)  
- Embedded Java HTTP Server  
- HTML (basic frontend rendering)  

---

## ▶️ How to Run the Project

1. Install Java (JDK 8 or later)
2. Clone the repository or download the source code
3. Navigate to the project directory
4. Compile the Java files:
   ```bash
   javac *.java
   ```
5. Run the server:
   ```bash
   java Main
   ```
6. Open a browser and visit:
   ```
   http://localhost:8080
   ```
